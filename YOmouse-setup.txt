🖐️YOtap: Studio-Level Gesture-Controlled Mouse SystemA high-performance, low-latency virtual mouse system powered by MediaPipe hand-skeleton tracking, OpenCV multithreading, and hardware-mapped Bluetooth neckband triggers—fully optimized for Python 3.14 on Windows.🛠️ System Architecture & Tech StackMotion Tracking: MediaPipe Tasks API (`HandLandmarker`) running 21-joint 3D hand skeleton detection.Performance Optimization: Dedicated background threading (`WebcamStream`) combined with Exponential Moving Average (EMA) filtering for zero-lag, buttery-smooth cursor movement.Hardware Triggering: `pynput` global keyboard listener mapping Bluetooth neckband media keys (Play/Pause, Next/Previous track) directly to HID mouse clicks.Environment: Python 3.14 + OpenCV + PyAutoGUI.📋 Prerequisites & InstallationMake sure you have Python 3.14 installed on Windows, then install the required dependencies:```pip install --upgrade opencv-python mediapipe pyautogui pynput```🚀 Setup & Execution GuideClone or Download this repository into your local workspace.Ensure your webcam is plugged in and your Bluetooth neckband is connected to your Windows PC.Open your terminal in the project directory and run the unified script:```   python unified_hand_mouse.py      ```(On first run, the script will automatically fetch the lightweight `hand_landmarker.task` AI model file).🕹️ How It WorksComponent	Action	DescriptionCursor Movement	Move your hand in front of the camera	The system tracks your Index Fingertip (Landmark 8) in real-time, maps the coordinates to your screen boundaries with edge padding, and applies an EMA smoothing filter to eliminate jitter.Left Click	Press Play / Pause on Neckband	Triggers a standard mouse left-click (`pyautogui.click()`).Right Click	Press Next Track on Neckband	Triggers a mouse right-click (`pyautogui.click(button='right')`).Double Click	Press Previous Track on Neckband	Triggers a mouse double-click (`pyautogui.doubleClick()`).Exit	Press `q` on the video window	Safely releases the camera stream and shuts down the application.📂 Project Structure```├── unified_hand_mouse.py      # Main script running tracking & neckband listener concurrently├── hand_landmarker.task       # MediaPipe neural network model (auto-downloaded on first run)└── README.md                  # Project documentation & tutorial```⚙️ Customization SettingsAdjust Smoothing: Open `unified_hand_mouse.py` and modify the `smoothening = 4.0` variable (higher values = smoother glide, lower values = faster response).Adjust Padding: Tweak `pad_x` and `pad_y` to match your comfortable camera reach zone.
